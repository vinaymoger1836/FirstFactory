## 5. Problems found and fixed

1. **Exceptions:** litellm's `NotFoundError` was not caught, so a job crashed and left S1 `running`. Fixed in two places: the router maps any non-retryable provider error to `LlmUnavailable`, and the stage template fails the run on any unexpected error (LangGraph interrupts pass through).
2. **Groq extractor model:** `llama-3.1-8b-instant` no longer exists. The extractor role now uses `groq/openai/gpt-oss-20b`.
3. **Gemini vision model:** `gemini-2.5-flash` is closed to new users, and `gemini-3.8-flash` / `flash-latest` returned 503 "high demand". Vision now uses `gemini/gemini-3.5-flash`.
4. **Vision failures:** a vision timeout or 503 paused the whole S1. docs/02 §7 says photo intake is skipped with a notice, so it now is (a budget stop still pauses). Errors after retries say "not responding" instead of "quota used up".
5. **One-variant datasheet:** a PB10K datasheet applied its values to PB20K too (false conflicts). A datasheet that names exactly one variant now applies to that variant only, and the prompt asks for the variant code.
6. **BoM mapping before template save:** per-variant qty columns were not found because the template is not saved when the wizard uploads. The upload now carries the variant codes. The extractor fallback no longer runs when per-variant qty columns were found.
7. **`migrate` never exited:** the checkpoint pool stayed open after `fl-agents setup`. Setup now uses one short-lived connection.
8. **Parallel image builds:** they timed out on uv's cache lock while one slow download held it; re-running with `UV_LOCK_TIMEOUT=1200` worked.
9. **TS tuple unions:** json-schema-to-typescript turned `maxItems` lists into unusable tuple unions. Fixed with `ignoreMinAndMaxItems`.
10. **Windows UTF-8:** `fl_domain.schema` printed to stdout in cp1252 on Windows; it now writes UTF-8 bytes.
